- 이메일 회원가입 → 로그인 상태 진입
- 폼에서 1,250자 + 메모 작성 → 성공 안내 → 새로고침 후 동일 기록 확인
- 원고지 2매 입력 → 400자로 환산·저장되는 것을 브라우저에서 확인
- 잔디의 해당 날짜 색상, 출석 1일, 누적 1,250자 반영
- 일반 회원의 `/admin` 접근 차단 화면
- 서버 CLI로 관리자 지정 → 전체 회원/출석 목록 렌더링
- 관리자에서 공지사항 편집·저장 → 대시보드에 실제 문구 반영
- 1440px 데스크톱 및 390px 모바일 점검
- 모바일 메뉴 → 마이페이지 이동
- 모바일 레이아웃의 가로 넘침 수정 후 `document.scrollWidth === innerWidth === 390` 확인

## 검증하지 못한 범위 / 남은 설정

- **YouBase 실서비스 인증·DB·실시간 연동·배포**: 연결된 프로젝트가 없어 미구현/미검증. `YOUBASE.md`의 명세로 플랫폼 내 이식 필요.
- **Google 실제 계정 OAuth**: 클라이언트 자격 증명 부재로 E2E 미검증. 코드는 포함됨.
- **Docker 컨테이너 빌드/Render 배포**: Docker 런타임·배포 계정 부재로 원격 검증 미수행. 구성 파일만 포함됨.
- 개발 서버 백그라운드 작업이 이 샌드박스에서 종료되어, 최종 UI 검증은 서버를 동일한 전경 도구 실행 안에서 시작/종료하는 방식으로 수행했습니다. 공개적으로 계속 실행되는 서버 주소를 제공하는 작업은 아닙니다.
- 대규모 부하, 여러 서버 확장, 모바일 실기기, 이메일 인증/비밀번호 복구, 개인정보 처리/보존 정책은 범위 밖입니다.
