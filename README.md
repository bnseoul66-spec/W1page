# WriteOn · 매일, 나를 쓰다

1인 크리에이터·지식 창업자를 위한 한국어 글쓰기 챌린지 웹 앱입니다.
React 프론트엔드, Node/Express 백엔드, 실제 SQLite 영구 저장소, 관리자 화면을 포함합니다.

> **중요 — YouBase 연결은 아직 완료되지 않았습니다.**
> 이 패키지는 독립 SQLite 서버에서 실제로 동작하는 앱입니다. YouBase 프로젝트/인증 SDK/배포 도구가 제공되지 않아 임의 API를 만들거나 연결 성공으로 표시하지 않았습니다. YouBase 데이터 모델과 이식 절차는 `docs/YOUBASE.md`에 있습니다. 실제 YouBase 연결에는 YouWare 프로젝트에서의 추가 서버·인증 구현과 검증이 필요합니다.
>
> Google OAuth 코드는 포함되어 있지만 본인의 Google 클라이언트 설정이 필요하며 실계정 로그인은 미검증입니다. 외부 서버에 실제 배포하지 않았습니다.

## 1. 바로 실행

Node.js **24 이상**과 pnpm이 필요합니다.

```bash
corepack enable
corepack prepare pnpm@10.17.1 --activate
pnpm install --frozen-lockfile
cp .env.example .env
pnpm dev
```

브라우저에서 `http://localhost:3000`을 여세요. 데이터베이스는 처음 실행할 때 `data/writeon.sqlite`에 자동 생성됩니다. 초기 데이터는 비어 있으며 가짜 잔디·통계·공용 계정이 없습니다.

1. 로그인 → 회원가입으로 본인 계정을 만듭니다.
2. 날짜, 글자 수 또는 원고지 분량, 메모와 링크를 입력합니다.
3. 저장 → 잔디·총 출석·연속 출석이 실제 DB 기록으로 갱신됩니다.
4. 브라우저 새로고침 또는 서버 재시작 후에도 동일한 기록을 확인할 수 있습니다.

## 2. 첫 관리자 만들기

웹에서 먼저 회원가입한 후 **서버 운영자만** 실행합니다.

```bash
pnpm admin your-registered-email@example.com
```

앱을 새로고침하면 관리자 메뉴가 나타납니다. `/admin`에서 회원별·날짜별 출석, 글 기록, 권한, 메인 헤더·공지·안내·포인트 색상을 관리합니다. 이후 관리자는 다른 회원에게 관리자 권한을 부여하거나 회수할 수 있습니다. 자신의 관리자 권한을 스스로 회수할 수는 없습니다. 최초 가입자에게 관리자 권한을 자동 부여하지 않습니다.

## 3. 구성된 기능

| 기능 | 구현 상태 |
|---|---|
| 이메일/비밀번호 회원가입·로그인·로그아웃 | SQLite 세션, scrypt 해싱, HttpOnly 쿠키로 동작 |
| Google 로그인 | Authorization Code + PKCE + state + nonce + ID token 검증 구현, 자격 증명 설정 필요 |
| 일별 기록 작성·수정·삭제 | 서버 검증, 사용자+날짜 유일키, 원고지 1매=200자 |
| 연간 GitHub형 잔디 | 사용자 실제 DB 조회 결과만 사용, 연도 이동·날짜 선택 |
| 연속 스트릭·누적 출석·챌린지 | KST 달력 날짜 기준, 공통 계산 함수 및 테스트 |
| 실시간 반영 | 저장 직후 재조회, 사용자 범위 SSE 알림, 15초 폴링 복구 |
| 마이페이지 | 이름·일일 목표 수정 |
| 기록 조회 | 날짜/메모 검색, 페이지 이동, JSON 다운로드 |
| 관리자 | 서버 권한 확인, 회원·날짜별 출석·기록 조회, 권한 변경 |
| 서비스 편집 | 헤더·공지·안내·색상 DB 저장, 회원 화면 반영 |
| 반응형 | PC 사이드바, 모바일 메뉴·단일 열 레이아웃, 가로 스크롤 잔디 |
| 배포 구성 | Dockerfile, Render Blueprint 및 `deploy.html` 런처 |
| YouBase 직접 연결·YouWare 원클릭 게시 | **미완료** — 플랫폼 프로젝트에서 이식 필요 |

## 4. 배포

프로젝트를 GitHub 저장소에 올린 후 `deploy.html`을 브라우저로 열어 저장소 URL을 입력하면 Render 배포 승인 화면으로 이동합니다. 서버·영구 디스크가 정의된 `render.yaml`을 사용합니다. **유료 서비스/디스크 요금을 검토하고 직접 승인해야 합니다.** 이 버튼은 YouBase 배포가 아닙니다.

배포·HTTPS·영구 디스크·Google·백업 안내: **`docs/DEPLOYMENT.md`**
YouBase 이식용 모델과 실행 요청: **`docs/YOUBASE.md`**
검증 결과와 제한: **`docs/VERIFICATION.md`**

```bash
pnpm test     # 날짜·권한·저장·재시작·SSE 자동 테스트
pnpm build    # dist/ 생성
# HTTPS reverse proxy 뒤에서 APP_ORIGIN을 실제 https 주소로 설정한 후:
pnpm start
```

## 5. 데이터 규칙

- 날짜 기준: **Asia/Seoul**. 날짜는 `YYYY-MM-DD`, 감사·생성 시각은 UTC.
- 출석: 1자 이상 기록한 고유 날짜. 하루 목표 달성 여부와 무관하게 출석.
- 같은 날짜를 다시 저장하면 기존 기록을 수정합니다. 횟수는 늘어나지 않습니다.
- 오늘 기록이 있으면 오늘부터, 없다면 어제부터 뒤로 이어진 날짜를 셉니다. 어제도 없으면 0일.
- 과거 기록 입력은 허용하며 과거 입력/수정/삭제 시 현재 통계도 다시 계산됩니다. 미래 기록은 금지.
- 챌린지는 회원 가입일부터 30일. `N일 차`는 경과한 달력 일수이며 출석 수와 다릅니다. 출석 달성률은 챌린지 기간 내 실제 고유 출석 날짜 수/30. 30일 이후에도 글 기록 가능.
- 스탬프는 챌린지 누적 출석의 달성 순서를 나타냅니다. 실제 날짜별 출석은 잔디에서 확인합니다.
- 잔디 분량 구간: 0, 1–499, 500–999, 1,000–1,999, 2,000자 이상.
- 글자 수는 직접 입력하는 분량입니다. 외부 링크의 글을 자동 수집·검증하지 않습니다.

## 6. 구조

```text
src/                     한국어 React UI, 반응형 스타일, 자체 호스팅 폰트

server/db.js             SQLite 연결, 초기 스키마 적용
server/index.js          개발 Vite 미들웨어 / 프로덕션 정적 파일 서버
shared/dates.js          KST 날짜·출석·스트릭 공통 함수
 database/schema.sql     실제 실행되는 SQLite 스키마
scripts/admin.js         서버 운영자 전용 관리자 부여
scripts/backup.js        일관된 SQLite 온라인 백업
 tests/                  통합·날짜 테스트
Dockerfile               Node 24 멀티스테이지, 비루트 실행
render.yaml              단일 인스턴스 + 영구 디스크 배포
```

## 7. 보안 및 운영 범위

소유자 ID는 클라이언트가 아닌 서버 세션에서 결정합니다. 모든 관리자 API에서 현재 DB의 권한을 확인하고, SQL은 매개변수 바인딩을 사용합니다. 링크는 http/https만 허용하며 사용자 문구는 React의 텍스트 이스케이프로 출력합니다. 변경 요청에는 정확한 Origin과 JSON Content-Type이 필요합니다. 로그인 시도·API 요청 제한, CSP 등 보안 헤더가 포함됩니다. 세션 토큰은 DB에 해시로만 저장됩니다. 권한·설정 변경은 감사 로그에 남습니다.

독립 모드는 이메일 소유 확인, 비밀번호 재설정, CAPTCHA, 계정 삭제/탈퇴, 다중 챌린지 회차 관리, 대규모 회원 페이징을 포함하지 않습니다. 실제 공개 운영 전 이메일 인증/복구, 개인정보 처리방침·보존 정책, 백업·복원 훈련, 모니터링을 추가하세요. SQLite 파일 자체는 암호화하지 않습니다. 호스팅 디스크/백업 암호화와 접근권한을 별도로 설정해야 합니다. 무료 서버리스/임시 파일시스템에는 배포하면 안 됩니다. 여러 서버로 수평 확장하는 구조가 아니라 영구 디스크를 사용하는 **단일 서버** 구조입니다.
